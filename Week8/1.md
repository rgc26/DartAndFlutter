

# Module 0 — Project Setup


## Objective

Set up your Zapp.run project with Firebase packages.

***

## Concept

Before writing any Flutter code, your project needs to know which external packages to use. In Flutter, packages are declared inside `pubspec.yaml`.

***

## What to Add

Open `pubspec.yaml` and under `dependencies:`, add these **2 lines**:

```yaml
firebase_core: ^2.4.1
cloud_firestore: ^4.3.0
```

It should look like this after:

```yaml
dependencies:
  flutter:
    sdk: flutter
  firebase_core: ^2.4.1      # connects Flutter to Firebase
  cloud_firestore: ^4.3.0    # lets you read/write Firestore database
```


***

## 

|  |  |
| :-- | :-- |
| `firebase_core` | Required to initialize any Firebase service |
| `cloud_firestore` | The database we use to store todo tasks |


***

## Expected Output

> The **Dependencies panel** on the left shows both packages loaded with **no red errors**.
