# Module 1 — CREATE

### Lesson 1.1 of 3

## Objective

Write the function that posts a task to Firestore.

## Concept

`.add({})` creates a new document in Firestore. Every task needs 3 fields: the text, a done status, and a timestamp.

## What to Add

Inside `_TodoScreenState`, paste this **below** `_controller`:

```dart
Future<void> _addTodo() async {
  final text = _controller.text.trim();
  if (text.isEmpty) return;
  await _todosRef.add({
    'title': text,
    'isDone': false,
    'createdAt': FieldValue.serverTimestamp(),
  });
  _controller.clear();
}
```


## 

|  |  |
| :-- | :-- |
| `_todosRef.add({})` | Creates a new document in `todos` collection |
| `text.isEmpty` | Blocks posting if the field is blank |
| `serverTimestamp()` | Records the exact time on Firebase server |
| `_controller.clear()` | Clears the text field after posting |

## Expected Output

> Method `_addTodo()` exists inside `_TodoScreenState` with no red underlines.

# Module 2 — READ

### Lesson 2.1 of 3

## Objective

Write the code that listens to Firestore in real time.

## Concept

`StreamBuilder` listens to a Firestore stream. Every time data changes in Firestore, the UI automatically rebuilds — no manual refresh needed.

## What to Add

Inside `build()` Column children, **below the Padding input bar**, add:

```dart
Expanded(
  child: StreamBuilder<QuerySnapshot>(
    stream: _todosRef
        .orderBy('createdAt', descending: true)
        .snapshots(),
    builder: (context, snapshot) {
      if (snapshot.connectionState == ConnectionState.waiting) {
        return const Center(child: CircularProgressIndicator());
      }
      if (snapshot.hasError) {
        return Center(child: Text('Error: ${snapshot.error}'));
      }
      if (!snapshot.hasData || snapshot.data!.docs.isEmpty) {
        return Center(
          child: Column(
            mainAxisSize: MainAxisSize.min,
            children: [
              Icon(Icons.checklist, size: 64, color: Colors.grey),
              SizedBox(height: 12),
              Text(
                'No tasks yet!\nAdd one above.',
                textAlign: TextAlign.center,
                style: TextStyle(color: Colors.grey, fontSize: 16),
              ),
            ],
          ),
        );
      }
      final docs = snapshot.data!.docs;
      return ListView.separated(
        padding: const EdgeInsets.symmetric(horizontal: 12),
        itemCount: docs.length,
        separatorBuilder: (_, __) => const Divider(height: 1),
        itemBuilder: (context, index) {
          final doc = docs[index];
          final data = doc.data() as Map<String, dynamic>;
          final title = data['title'] as String? ?? '';
          return ListTile(
            title: Text(title),
          );
        },
      );
    },
  ),
),
```


## 

|  |  |
| :-- | :-- |
| `.snapshots()` | Returns a live stream from Firestore |
| `ConnectionState.waiting` | Shows spinner while loading |
| `docs.isEmpty` | Shows empty state when no tasks |
| `ListView.separated` | Renders tasks with a divider between each |

## Expected Output

> Tasks from Lesson 1.3 now appear in the list instantly.

# Module 3 — UPDATE

### Lesson 3.1 of 3

## Objective

Write the functions that toggle done and edit a task title.

## Concept

`.update({})` modifies specific fields of an existing document without touching the rest. You target the exact document using `.doc(id)`.

## What to Add

Inside `_TodoScreenState`, add these 2 methods below `_addTodo`:

```dart
Future<void> _toggleDone(String id, bool current) async {
  await _todosRef.doc(id).update({'isDone': !current});
}

Future<void> _editTodo(String id, String currentTitle) async {
  final editController = TextEditingController(text: currentTitle);
  await showDialog(
    context: context,
    builder: (ctx) => AlertDialog(
      title: const Text('Edit Task'),
      content: TextField(
        controller: editController,
        autofocus: true,
        decoration: const InputDecoration(border: OutlineInputBorder()),
      ),
      actions: [
        TextButton(
          onPressed: () => Navigator.pop(ctx),
          child: const Text('Cancel'),
        ),
        ElevatedButton(
          onPressed: () async {
            final newTitle = editController.text.trim();
            if (newTitle.isNotEmpty) {
              await _todosRef.doc(id).update({'title': newTitle});
            }
            Navigator.pop(ctx);
          },
          child: const Text('Save'),
        ),
      ],
    ),
  );
}
```


## 

|  |  |
| :-- | :-- |
| `.doc(id)` | Targets one specific document by its Firestore ID |
| `.update({})` | Only changes the fields you specify |
| `!current` | Flips `true to false` and `false to true` |
| `showDialog` | Opens a popup for the user to type a new title |

## Expected Output

> Both methods exist in `_TodoScreenState` with no red underlines.

# Module 4 — DELETE

### Lesson 4.1 of 2

## Objective

Write the function that permanently removes a task from Firestore.

## Concept

`.delete()` removes the entire document from Firestore. Unlike `.update()`, this cannot be undone.

## What to Add

Inside `_TodoScreenState`, add this method below `_editTodo`:

```dart
Future<void> _deleteTodo(String id) async {
  await _todosRef.doc(id).delete();
}
```


## 

|  |  |
| :-- | :-- |
| `.doc(id)` | Finds the exact document to remove |
| `.delete()` | Permanently deletes it from Firestore |

## Expected Output

> Method `_deleteTodo()` exists with no red underlines.
