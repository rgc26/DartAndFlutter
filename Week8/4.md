

# Module 0 — Project Setup

### Lesson 0.4 of 5

##  Objective

Initialize Firebase inside `main.dart` and confirm the connection works.

***

## Concept

Before Flutter can talk to Firebase, you must **initialize** it at app startup. This is done once inside `main()` before `runApp()` is called.

***

## What to Add

Open `lib/main.dart` and update **only these 2 parts**:

### Part A — Add imports at the top

```dart
import 'package:firebase_core/firebase_core.dart';
import 'firebase_options.dart';
```


### Part B — Update `main()` to initialize Firebase

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  runApp(const MyApp());
}
```


### Part C — Temporarily update `home:` to test connection

```dart
home: const Scaffold(
  body: Center(
    child: Text('Firebase Connected!'),
  ),
),
```

Click **Run**.

***

## 

|  |  |
| :-- | :-- |
| `WidgetsFlutterBinding.ensureInitialized()` | Required before any async work in `main()` |
| `Firebase.initializeApp()` | Starts the Firebase connection using your config |
| `await` | Waits for Firebase to finish connecting before the app opens |


***

## Expected Output

> Screen shows **" Firebase Connected!"** with **no errors** in the Logs panel.

## If you see an error

> Go back to `firebase_options.dart` and double check every value is correct — one wrong character causes a failure.
