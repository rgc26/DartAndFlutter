# Module 0 — Project Setup

### Lesson 0.3 of 5

## Objective

Create the file that connects Flutter to your Firebase project.

***

## Concept

Flutter needs your Firebase config values in a Dart file so the app knows **which Firebase project** to connect to when it runs.

***

## What to Do

1. Inside `lib/`, create a **new file** → name it `firebase_options.dart`
2. Add this code and **replace every `YOUR_...`** with your saved values from Lesson 0.2:
```dart
import 'package:firebase_core/firebase_core.dart' show FirebaseOptions;
import 'package:flutter/foundation.dart' show kIsWeb;

class DefaultFirebaseOptions {
  static FirebaseOptions get currentPlatform {
    if (kIsWeb) return web;
    throw UnsupportedError('Only web is supported on Zapp.run.');
  }

  static const FirebaseOptions web = FirebaseOptions(
    apiKey:            'YOUR_API_KEY',
    appId:             'YOUR_APP_ID',
    messagingSenderId: 'YOUR_MESSAGING_SENDER_ID',
    projectId:         'YOUR_PROJECT_ID',
    authDomain:        'YOUR_PROJECT_ID.firebaseapp.com',
    storageBucket:     'YOUR_PROJECT_ID.appspot.com',
  );
}
```


***

## 

|  |  |
| :-- | :-- |
| `kIsWeb` | Checks if the app is running on web (Zapp.run is web only) |
| `apiKey` | Identifies your Firebase project |
| `projectId` | The unique name of your Firebase project |
| `authDomain` | Where Firebase handles authentication |


***

## Expected Output

> - File `firebase_options.dart` appears under `lib/` 
> - All `YOUR_...` are replaced with real values 
> - **No red underlines** in the file 

##  Common Mistake

> `authDomain` and `storageBucket` are **not** in the config box — you build them yourself by replacing `YOUR_PROJECT_ID` with your actual `projectId` value.
