

# Module 0 — Project Setup

### Lesson 0.5 of 5

## Objective

Add Firestore to `main.dart` and point it to your `todos` collection.

***

## Concept

`CollectionReference` is like a **pointer** to a specific table in your Firestore database. You declare it once and reuse it for all CRUD operations.

***

## What to Add

### Part A — Add import at the top

```dart
import 'package:cloud_firestore/cloud_firestore.dart';
```


### Part B — Add collection reference inside `_TodoScreenState`

```dart
final CollectionReference _todosRef =
    FirebaseFirestore.instance.collection('todos');
```


### Part C — Remove the test text from Lesson 0.4

Change `home:` back to:

```dart
home: const TodoScreen(),
```


***

## 
|  |  |
| :-- | :-- |
| `FirebaseFirestore.instance` | Gets the Firestore database instance |
| `.collection('todos')` | Points to the `todos` collection in your database |
| `_todosRef` | Reusable variable — all CRUD methods will use this |


***

## Expected Output

> - App runs and shows a **blank screen with AppBar** 
> - No errors in the Logs panel 
> - `_todosRef` is ready to be used in the next modules
