

# Module 0 — Project Setup

### Lesson 0.2 of 5

## Objective

Create your Firebase project and get your config credentials.

***

## Concept

Firebase needs to know your app exists before it can store data. You do this by registering your app in the Firebase Console and copying the config it gives you.

***

## What to Do

### Part A — Create Firebase Project

1. Go to [console.firebase.google.com](https://console.firebase.google.com)
2. Click **Add project**
3. Name it `flutter-todo-app`
4. Disable Google Analytics
5. Click **Create project**

### Part B — Register Web App

1. Click the **`</>`** Web icon on the dashboard
2. Nickname: `todo-web` → Click **Register app**
3. **Save these 4 values** to a notepad:
```
apiKey:            "copy this"
projectId:         "copy this"
messagingSenderId: "copy this"
appId:             "copy this"
```

4. Click **Continue to console**

### Part C — Create Firestore Database

1. Left menu → **Build → Firestore Database**
2. **Create database** → **Start in test mode** → Click **Enable**

### Part D — Fix Security Rules

1. Firestore → **Rules** tab → replace with:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

2. Click **Publish**

***

## Expected Output

> - Firebase dashboard shows project `flutter-todo-app` 
> - 4 config values saved on your notepad 
> - Firestore shows an empty database 
> - Rules show **"Published"**
