```yaml
dependencies:
  flutter:
    sdk: flutter
  http: ^0.13.6
  shared_preferences: ^2.2.2    # ← ADD THIS LINE
```

**Why `shared_preferences`?**


|  | |
| :-- | :-- |
| Persistence | Saves small data (strings, bools) to the device's local storage |
| Survives app restarts | Unlike a variable, it stays saved even after closing the app |
| No database needed | For simple data like "last city typed", a full database is overkill |

## Part 1 — °F / °C Toggle

> All changes are still **only inside `home_screen.dart`** unless stated otherwise.

***

### Step 1A: Add a New State Variable

Inside `_HomeScreenState`, add one new variable below your existing ones:

```dart
  bool _isCelsius = true;
```

**What this means:**

|  | |
| :-- | :-- |
| `bool` | Holds either `true` or `false` — two states, perfect for a toggle |
| `_isCelsius = true` | Starts in Celsius mode by default |


***

### Step 1B: Add the Temperature Converter Method

Add this method inside `_HomeScreenState`, above `build()`:

```dart
  double _getDisplayTemp() {
    if (_weather == null) return 0.0;
    if (_isCelsius) return _weather!.temperature;
    return (_weather!.temperature * 9 / 5) + 32;
  }
```

|  | |
| :-- | :-- |
| `double _getDisplayTemp()` | Returns a `double` — the converted temperature |
| `if (_weather == null) return 0.0` | Guard clause — if no data yet, return zero safely |
| `if (_isCelsius) return _weather!.temperature` | Celsius mode — return the raw API value with no conversion |
| `return (_weather!.temperature * 9 / 5) + 32` | The standard °C to °F formula — `32.5°C` becomes `90.5°F` |

> The formula is $F = (C \times \frac{9}{5}) + 32$. Always multiply **before** adding 32 — Dart follows standard math operator precedence so no extra parentheses are needed for the multiplication.

***

### Step 1C: Add the Toggle Button in `build()`

Find the `AppBar` in your `build()` method:

```dart
appBar: AppBar(
  title: const Text('Weather App'),
  centerTitle: true,
  backgroundColor: Colors.transparent,
  elevation: 0,
),
```

Replace it with:

```dart
appBar: AppBar(
  title: const Text('Weather App'),
  centerTitle: true,
  backgroundColor: Colors.transparent,
  elevation: 0,
  actions: [
    Padding(
      padding: const EdgeInsets.only(right: 12),
      child: GestureDetector(
        onTap: () {
          setState(() {
            _isCelsius = !_isCelsius;
          });
        },
        child: Chip(
          label: Text(_isCelsius ? '°C' : '°F'),
        ),
      ),
    ),
  ],
),
```

|  | |
| :-- | :-- |
| `actions: [...]` | The AppBar's right-side widget slot — for icons or buttons |
| `Padding(right: 12)` | Pushes the chip away from the screen edge |
| `GestureDetector` | Wraps any widget and makes it tappable — more flexible than `ElevatedButton` |
| `onTap: () { setState(...) }` | On tap, flip `_isCelsius` and redraw the screen |
| `_isCelsius = !_isCelsius` | The `!` operator flips `true` → `false` and `false` → `true` |
| `Chip` | A small rounded label widget — perfect for a toggle indicator |
| `Text(_isCelsius ? '°C' : '°F')` | Shows the **current** unit so the user always knows which mode is active |

### Step 1D: Update the Temperature Display

Find this line inside the weather card:

```dart
Text(
  '${_weather!.temperature}°C',
  style: const TextStyle(
    fontSize: 48,
    fontWeight: FontWeight.bold,
  ),

```

Replace it with:

```dart
Text(

  style: const TextStyle(
    fontSize: 48,
    fontWeight: FontWeight.bold,
  ),
),
```

**What changed, word by word:**


|  | |
| :-- | :-- |
| `_getDisplayTemp()` | Calls your converter — returns Celsius or Fahrenheit depending on toggle |
| `.toStringAsFixed(1)` | Formats the number to **1 decimal place** — `90.5` not `90.500000` |
| `${_isCelsius ? '°C' : '°F'}` | Appends the correct unit label after the number |

## Part 2 — Save Last Searched City


***

### Step 2A: Import `shared_preferences`

Add this import at the top of `home_screen.dart`, below your existing imports:

```dart
import 'package:shared_preferences/shared_preferences.dart';
```

**Why?**

- `shared_preferences` gives you `SharedPreferences.getInstance()` — a key-value store on the device
- Without this import, Dart doesn't know what `SharedPreferences` is

***

### Step 2B: Add the Save Method

Add this method inside `_HomeScreenState`, below `dispose()`:

```dart
  Future<void> _saveLastCity(String city) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString('last_city', city);
  }
```


|  | |
| :-- | :-- |
| `Future<void>` | Async method — writing to storage takes a moment |
| `SharedPreferences.getInstance()` | Gets the single shared storage instance for your app |
| `prefs.setString('last_city', city)` | Saves the city under the key `'last_city'` — like a dictionary |
| `await` on both lines | Both operations are async — you must wait for each to finish before continuing |


***

### Step 2C: Add the Load Method

Add this method directly below `_saveLastCity`:

```dart
  Future<void> _loadLastCity() async {
    final prefs = await SharedPreferences.getInstance();
    final lastCity = prefs.getString('last_city');
    if (lastCity != null) {
      _controller.text = lastCity;
    }
  }
```


|  | |
| :-- | :-- |
| `prefs.getString('last_city')` | Reads back the value saved under `'last_city'` — returns `null` if nothing was ever saved |
| `final lastCity = ...` | Stores the result — could be a city name or `null` |
| `if (lastCity != null)` | Only update the field if a city was actually saved before |
| `_controller.text = lastCity` | Pre-fills the `TextField` with the last city — user sees it immediately on open |


***

### Step 2D: Call `_loadLastCity()` on Screen Init

Add the `initState()` method inside `_HomeScreenState`, directly **above** `dispose()`:

```dart
  @override
  void initState() {
    super.initState();
    _loadLastCity();
  }
```

|  | |
| :-- | :-- |
| `initState()` | Called **once** automatically when the screen is first created |
| `super.initState()` | Always call this **first** — lets the parent class initialize before you run your code |
| `_loadLastCity()` | Runs immediately on open — fills the TextField if a city was previously saved |

> `super.initState()` must always be the **first line** in `initState()`. The opposite rule from `dispose()` where `super` goes last.

***

### Step 2E: Call `_saveLastCity()` on Successful Fetch

Inside `_fetchWeather()`, find the try block where you update `_weather`:

```dart
      final weather = await _service.fetchWeather(_controller.text);
      setState(() {
        _weather = weather;
        _isLoading = false;
      });
```

Add one line after the `await`:

```dart
      final weather = await _service.fetchWeather(_controller.text);
      await _saveLastCity(_controller.text);   // ← ADD THIS LINE
      setState(() {
        _weather = weather;
        _isLoading = false;
      });
```

**Why here?**

- You only save the city **after** a successful API call — not on errors
- If the city name was wrong (404), you don't want to save it as the "last city"
- Placing it before `setState()` ensures it's saved before the screen redraws

> **Test:** Search `Manila`. Close the app completely on `zapp.run` (refresh the tab). Reopen — the TextField should already say `Manila`. Search a new city like `Tokyo` — refresh again — the TextField should now say `Tokyo`.
